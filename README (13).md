# 1a. Create a Spring Boot project using Spring Initializr

**Aim:** To create and run a Spring Boot application using Spring Initializr (https://start.spring.io/ - Maven, Java, Spring Web).

## How to run
```bash
mvn spring-boot:run
```

## Expected output
```
http://localhost:8080/       ->  Welcome to Spring Boot Application
http://localhost:8080/hello  ->  Hello World from Spring Boot!
```
