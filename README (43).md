# 2c. Web application using Spring MVC

**Aim:** To build a web application with Spring Web MVC that handles HTTP requests using @RestController, @GetMapping and @RequestParam.

## How to run
```bash
mvn spring-boot:run
```

## Expected output
```
http://localhost:8080/                          ->  Welcome to Aditya University's Portal!
http://localhost:8080/greet?name=Aditya_Learner  ->  Greetings, Aditya_Learner! Welcome to your Spring Web MVC Dashboard.
```
